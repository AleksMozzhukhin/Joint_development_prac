Клиентский модуль
=================

Клиентский модуль содержит интерфейс командной строки для взаимодействия с сервером MOOD.
Он предоставляет пользователю возможность подключаться к серверу, отправлять команды и получать ответы.

Основные компоненты
-------------------

* **Игровой клиент** (`game_client.py`) - основной класс клиента
* **Система команд** - обработка пользовательских команд
* **Асинхронный ввод-вывод** - обработка сообщений от сервера
