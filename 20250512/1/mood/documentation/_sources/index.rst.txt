Документация игры MOOD
======================

MOOD (MUD with cowsay) - многопользовательская текстовая игра.

Введение
--------

MOOD — это многопользовательская текстовая игра (MUD) с интеграцией cowsay для отображения монстров.
Игра поддерживает множественных игроков, перемещение по игровому полю, сражения с монстрами и
интерактивное общение между игроками.

Особенности
-----------

* **Многопользовательский режим** - одновременная игра нескольких игроков
* **Система монстров** - добавление и сражение с различными существами
* **Бродячие монстры** - автоматическое перемещение монстров каждые 30 секунд
* **Интеграция с cowsay** - красивое отображение монстров в ASCII-арт
* **Локализация** - поддержка русского и английского языков
* **Система оружия** - различные виды оружия с разным уроном

Архитектура
-----------

Проект состоит из трех основных модулей:

* **Серверный модуль** (`mood.server`) - обработка подключений, игровая логика
* **Клиентский модуль** (`mood.client`) - пользовательский интерфейс и взаимодействие с сервером
* **Общие компоненты** (`mood.common`) - константы и общие утилиты

Быстрый старт
-------------

Для запуска сервера:

.. code-block:: bash

   python -m mood.server --host localhost --port 65432

Для подключения клиента:

.. code-block:: bash

   python -m mood.client --host localhost --port 65432 --username player1
