Серверный модуль

Серверный модуль содержит всю логику игрового сервера MOOD, включая обработку подключений клиентов, управление игровым состоянием, систему монстров и локализацию.

Основные компоненты

Модуль сервера состоит из следующих основных компонентов:

  • Игровой сервер (game_server.py) - основная серверная логика

  • Система локализации - поддержка многоязычности

  • Система бродячих монстров - автоматическое перемещение монстров

Основной модуль сервера

Модуль серверной части игры MOOD.

Этот модуль содержит реализацию серверной логики многопользовательской текстовой игры MOOD. Он обрабатывает подключения клиентов, управляет состоянием игры и взаимодействует с игроками.

async mood.server.game_server.broadcast_message(message, exclude_writer=None, format_args=None)[исходный код]

Отправить сообщение всем подключенным клиентам, кроме исключенного.

Функция проходит по всем подключенным клиентам и отправляет им указанное сообщение с учетом локали каждого клиента.

Параметры:

  • message – Сообщение для отправки (может содержать {} для форматирования).

  • exclude_writer – Клиент, которому не нужно отправлять сообщение.

  • format_args – Словарь с аргументами для форматирования сообщения.

async mood.server.game_server.move_monsters()[исходный код]

Периодически перемещать случайных монстров в случайном направлении.

Эта асинхронная функция запускается как отдельная задача и каждые 30 секунд выбирает случайного монстра и пытается переместить его в случайном направлении. Если выбранное направление занято другим монстром, функция выбирает другого монстра и направление, пока не найдет свободную клетку. При успешном перемещении всем игрокам отправляется сообщение о движении монстра. Если на новой позиции находятся игроки, инициируется «энкаунтер».
